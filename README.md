# Number Guessing Game
**Description:** This is a little number guessing game I created back in 2022 using Java and the java.util package Scanner. I utilize if statements and a while loop for functionality as well as a try catch statement to ensure that only Integers are being guessed. I also included a runner file to simplify the start of the game.
